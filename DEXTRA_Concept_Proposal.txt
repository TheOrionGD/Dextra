1.  Executive Summary 
DEXTRA is a software solution that replaces the conventional computer mouse with real-time hand gesture recognition via a standard webcam. Using Google's MediaPipe framework for hand landmark detection, DEXTRA maps natural hand gestures to every standard mouse operation — including cursor movement, left and right clicking, double-clicking, drag-and-drop, and scrolling — without any additional hardware.
DEXTRA is further enhanced by a voice command engine (40+ spoken commands across 6 categories), a browser-based settings GUI for personalisation, and a gesture trainer module that allows users to record and assign custom gestures to system shortcuts. The entire solution is delivered as a modular Python application targeting Windows, with a clear path to macOS and Linux.
Key Value:  DEXTRA delivers a fully mouse-free computing experience using 22 hand gestures, 40+ voice commands, and a standard laptop webcam — no specialised hardware required.
2.  Problem Statement
The physical mouse has remained the dominant pointing device for over four decades. While reliable, it presents barriers in several real-world scenarios:
Accessibility: Users with limited hand mobility or physical disabilities struggle with precise mouse control.
Hygiene-sensitive environments: Medical and laboratory settings require touchless interaction with computer systems.
Space constraints: Mobile workers and students in crowded spaces often lack a flat surface for mouse operation.
AR/VR and kiosk environments: Emerging interfaces have no surface on which a physical mouse can operate.
Fatigue and repetitive strain: Prolonged mouse use contributes to RSI (Repetitive Strain Injury).
A gesture-based alternative addresses all five scenarios simultaneously, offering a natural, hardware-free, and hygienic input method.
3.  Proposed Solution
DEXTRA uses a webcam to capture the user's hand in real time. MediaPipe's hand-tracking model identifies 21 landmark points on the hand at 30+ frames per second. A Python logic layer interprets the spatial relationships between these landmarks to recognise gestures, which are then translated into system-level mouse events via PyAutoGUI.

3.3  Settings GUI
A React-based dark-themed settings panel (served locally via FastAPI) allows users to tune all system parameters through a browser UI without editing code. Adjustable settings include:
Camera index (built-in vs. external webcam)
Cursor smoothing level (1–15 frame buffer)
Click threshold distance in pixels
Drag hold time and double-click timing
Action cooldown period
Toggle switches for voice commands and gesture trainer
3.4  Gesture Trainer
The gesture trainer provides a live camera preview with real-time finger-state detection. Users hold a chosen hand shape, name it, and map it to any of 14 available system actions. Saved gestures are stored in a JSON file and loaded automatically on startup. Custom gestures take priority over built-in gestures in the recognition pipeline.
4.  System Architecture
DEXTRA is structured as five independent modules that communicate via shared state and a thread-safe queue:
Module | Responsibility
main.py | Entry point — launches any module from an interactive menu.
gesture_mouse.py | Core engine — captures frames, runs MediaPipe, maps gestures to PyAutoGUI calls.
voice_commands.py | Daemon thread — listens for speech and pushes recognised commands to a shared queue.
gui_server.py | FastAPI server — bridges the React frontend to settings.json and the webcam stream via REST and WebSocket.
settings_gui.py | React page (Settings) — dark-themed browser panel with sliders and toggles that reads/writes settings via the API.
gesture_trainer.py | React page (Trainer) — live camera preview (WebSocket JPEG stream) for recording and persisting custom gestures to JSON.

4.1  Data Flow
The processing pipeline follows a linear chain on each video frame:
1 | Webcam Frame | OpenCV captures a raw BGR frame at 30+ FPS
2 | Pre-processing | Frame is flipped (mirrored) and converted to RGB
3 | Hand Detection | MediaPipe locates 21 landmark coordinates on the hand
4 | Gesture Logic | Python checks finger states and pinch distances
5 | Coordinate Map | NumPy interpolates landmark position to screen resolution
6 | Smoothing | Moving average buffer removes cursor jitter
7 | Mouse Execution | PyAutoGUI issues the OS-level mouse event
8 | UI Overlay | OpenCV draws the current action label on the preview window

7.  DEXTRA  —  Challenges & Mitigations
Challenge | Risk | Mitigation
Cursor jitter | Hand tremor causes cursor instability | Moving average smoothing buffer (configurable 1–15 frames)
Accidental clicks | Unintended pinches trigger actions | Configurable cooldown timer + click distance threshold
Poor lighting | Low light reduces MediaPipe accuracy | Confidence threshold tuning; recommend ambient lighting guidance
Gorilla arm fatigue | Holding arm up causes muscle fatigue | Rest mode gesture; adjustable camera angle reduces arm elevation
Background noise | Voice commands misfire in noisy rooms | SpeechRecognition ambient noise calibration on startup
Screen edge accuracy | Cursor precision drops at screen edges | Remapped coordinate interpolation with 10% margin exclusion zones

10.  Conclusion
DEXTRA demonstrates that a practical, hardware-free mouse replacement is achievable today using freely available open-source tools. By combining MediaPipe's accurate hand tracking with Python's rich ecosystem, DEXTRA delivers all standard mouse operations through natural hand gestures, supplemented by voice commands for keyboard shortcuts and a React-powered browser GUI for configuration.
The modular architecture ensures that each component — gesture recognition, voice control, settings management, and gesture training — can be developed, tested, and improved independently. The roadmap for future enhancements positions DEXTRA for growth into accessibility tools, AR/VR interfaces, and cross-platform deployment.
DEXTRA is immediately buildable with a standard webcam and a minimal open-source stack, making it an ideal candidate for rapid prototyping, portfolio demonstration, or production deployment in accessibility and touchless-interface contexts.
