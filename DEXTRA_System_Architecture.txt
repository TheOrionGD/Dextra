========================================================================
                      DEXTRA PROJECT TEAM DETAILS
========================================================================

Technology Stack
----------------
- Frontend: React 18+ (scaffolded via Vite CLI)
- Backend: FastAPI, uvicorn
- Computer Vision: OpenCV, MediaPipe
- Audio Processing: Hugging Face Transformers, sounddevice, soundfile
- Mouse Control & OS Integration: PyAutoGUI, NumPy

========================================================================
TEAM MEMBER ASSIGNMENTS & RESPONSIBILITIES
========================================================================

1. SALMAN - Core Gesture & Tracking Engine
------------------------------------------
- Assigned Modules:
  * `python/camera.py`: Frame capture and camera configs.
  * `python/gesture_engine.py`: MediaPipe hands tracking.
  * `python/gesture_mapping.py`: Mouse event maps and smoothing coordinates.
- Key Responsibilities:
  * Implement video capture loops and camera frame extraction.
  * Initialize MediaPipe Hands to isolate 21 landmarks at >=30 FPS.
  * Develop smoothing moving average coordinates and mapping coordinates to screen dimensions.
  * Trigger click, scroll, double-click, and drag-and-drop operations via PyAutoGUI.
- Models & APIs:
  * Google MediaPipe Hands framework
  * OpenCV VideoCapture API
  * PyAutoGUI execution library
  * NumPy mathematical arrays
- Helper & Sample Test Cases to Pass:
  * Capture loop runs without lag or frame drops.
  * Coordinate translation maps index finger tip position to screen coordinates.
  * Gesture state freeze ("Open Palm") suspends input activity.

2. LOGESH - Voice Command Engine
--------------------------------
- Assigned Modules:
  * `python/voice_wakeword.py`: Listens for custom trigger word "DEXTRA".
  * `python/voice_engine.py`: Runs Hugging Face transcription.
  * `python/voice_mapping.py`: Maps transcription strings to hotkeys.
- Key Responsibilities:
  * Set up background audio streaming using sounddevice.
  * Build a wakeword classifier checking incoming sound blocks for "DEXTRA".
  * Integrate Hugging Face transformers pipeline (e.g. Whisper) to convert audio buffers to text.
  * Match transcribed queries to 40+ system hotkeys.
- Models & APIs:
  * Hugging Face Transformers ASR Pipeline (e.g., openai/whisper-tiny)
  * PyTorch framework
  * Sounddevice and Soundfile audio drivers
  * PyAutoGUI hotkey commands
- Helper & Sample Test Cases to Pass:
  * Wakeword trigger is detected in background streams.
  * Speech-to-text transcribes speech blocks in under 500ms.
  * Transcribed text commands match targeting PyAutoGUI key hotkeys.

3. MUTHAMIL - FastAPI Backend GUI Server
-----------------------------------------
- Assigned Modules:
  * `python/config.py`: Local configurations read/write layers.
  * `python/gui_server.py`: FastAPI REST and WebSockets.
  * `python/main.py`: Launcher CLI system.
- Key Responsibilities:
  * Handle read/write lock synchronization on config parameters files.
  * Expose REST routes for saving configuration settings.
  * Stream annotated OpenCV image frames to the frontend WebSockets receiver.
  * Orchestrate backend thread activations and process states.
- Models & APIs:
  * FastAPI REST API router
  * Uvicorn ASGI server
  * WebSockets framework
- Helper & Sample Test Cases to Pass:
  * Bind and boot uvicorn web server listening on port 8000.
  * JSON payloads are validated and persisted in dextra_settings.json.
  * WebSockets connection handles client disconnections.

4. GODFREY - React Settings & Trainer SPA
------------------------------------------
- Assigned Module: `gui/` React Project
- Key Responsibilities:
  * Implement Vite CLI project structures and UI layouts.
  * Create component form bindings to settings parameters.
  * Build WebSocket client connection canvas renderer.
  * Expose voice activation control switches (`gui/src/components/VoiceController.jsx`).
- Models & APIs:
  * React Router v6
  * Fetch API REST interface
  * HTML5 WebSocket interface
- Helper & Sample Test Cases to Pass:
  * Run Vite server successfully on localhost:5173.
  * Form inputs serialize config values correctly.
  * Draw incoming image bytes onto canvas dynamically at 30 FPS.

- Milestones: Complete system runs concurrently under 30% CPU load; UI looks sleek.

Days 13–14: QA Testing, Performance Tuning & Deployment Packaging

- Milestones: Zero-install running capabilities verified; deployment package ready.
